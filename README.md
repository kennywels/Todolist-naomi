# Todo List — Ionic / Angular

A simple task-management application built with **Ionic 5**, **Angular 10**, **Firebase** and **Capacitor**.

This repository is an earlier learning/project build and is kept public as part of my development history.

## Tech stack

- Ionic 5
- Angular 10
- TypeScript
- Firebase
- Capacitor
- SCSS

## Project goals

The project explores the fundamentals of building a cross-platform application with Ionic and Angular, including task management, Angular application structure, Ionic UI components, Firebase integration, and mobile-oriented application development.

## Getting started

### Prerequisites

- Node.js
- npm
- Ionic CLI

### Installation

```bash
git clone https://github.com/kennywels/Todolist-naomi.git
cd Todolist-naomi
npm install
```

Start the development server:

```bash
npm start
```

## Available scripts

```bash
npm start
npm run build
npm test
npm run lint
```
