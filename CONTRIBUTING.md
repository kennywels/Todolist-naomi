# Contributing

This repository is primarily a personal learning project.

Suggestions and improvements are welcome, especially when they help make the code clearer, safer, or easier to understand.

## Before submitting changes

1. Keep changes focused and easy to review.
2. Never commit secrets, API keys, or credentials.
3. Keep documentation updated when behavior changes.
4. Use clear commit messages.

For larger changes, open an issue first to discuss the proposed direction.
